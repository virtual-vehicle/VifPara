# Installation

Installation of VifPara is as simple as to setup a virtual environment with a certain Python version and
install VifPara with pip.

## Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install vifpara
```

## Windows

```powershell
python -m venv venv
./venv/Scripts/Activate.ps1
pip install vifpara
```
